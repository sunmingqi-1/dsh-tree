# 悬浮卡片与原生输入（0.6.2）

## 交互与布局

默认卡片 560 × 360px，最小 420 × 300px。保留已有手动尺寸。顶部用紧凑悬浮栏显示节点类型、问题和可点击的来源摘录，背景使用原生输入框的 `--dsw-specific-input-major`，与正文背景区分；移除重复的区域标签、轮数、「展开阅读」和恢复尺寸按钮。卡头空白和拖动提示用于移动，问题文本可选择和滚动。

完整 Markdown 使用全卡大小的滚动视口。顶部悬浮栏和底部输入框覆盖正文；正文的渐变遮罩根据两者实际高度更新，外沿完全透明，阅读区过渡约 24px。正文初始、末尾的 padding 保证首尾内容均能滚到遮罩之外。未选中卡片也保留底部安全留白。不能用缩短滚动视口替代遮罩，否则会失去用户要求的悬浮效果。

卡片输入使用实际 DSH InputBar，保留默认加号、权限、模型、麦克风和发送能力，移除自定义「引用全文」。紧凑样式限制文本区最大高度 72px，并隐藏卡片内的统计行；测试数据下空编辑器总高度为 82px。右侧原生输入区不受这些样式影响。划词弹层复用同一原生组件，保留引用、编辑和发送，简化权限、模型等辅助控件。选区高亮独立于编辑器焦点。

底部工具栏采用分组、统一按钮高度和圆角，连线菜单替换为圆角弹层，支持键盘选择和关闭，窄窗口保持在视口内。「以学习画布开始」入口保留，进入该模式后不再显示「学习画布已启用」按钮。

## 原生输入的会话隔离

DSH 的原生编辑器在同一 Session 中只能绑定一个 DOM root。卡片输入与右侧输入因此绑定不同会话：准备卡片输入时，按父节点已完成的 `endSeq` fork；按父节点、输入用途和引用锚点缓存未发送会话。划词弹层也有独立会话，来源卡草稿不被覆盖。未发送准备会话不显示为独立学习节点；这些会话仍是宿主真实会话，频繁访问不同引用会增加缓存会话数量，尚未自动清理。

原生 InputBar 通过插件命名空间的 slot 别名复用，保留原注册的组件及其子控件。`SessionProvider` 接收已 retain 的会话引用；会话 Store 采用 `session` scope。额外绑定宿主 `conversation.session` 的草稿保存方法，使卡片切换和重载后恢复原生草稿。旧自定义文本草稿仅迁移一次。

输入、附件、指令与提交走宿主原生流程。观察 accepted 的 `user/message`，按 Session 和 rpcId 去重后记录子节点；引用使用宿主原生引用块。只有提交正文仍含原引用时，才为新节点保留引用锚点。已提交但节点保存失败的元数据先存本地，刷新后补记稳定 ID，不再次向模型发送。切换卡片时保留正在提交的观察，空闲引用及时释放。

此适配固定 DSH 0.2.2-rc.3。升级需验证 slot 注册、Store scope、草稿保存、SessionProvider、模型/权限/附件与语音插件组合。没有修改宿主源码。

## 缩放绘制策略

0.6.0 在缩放时切为 `will-change: auto`，允许每个中间比例重新绘制，改善了用户观察到的文字清晰度，但连续缩放增加了长文的绘制开销。0.6.1 改为平移和缩放手势期间使用 `transform` 合成提示，复用绘制层；缩放结束后切回 `auto`，按最终比例重新绘制。按钮和自动布局触发的缩放同样处理。只更新视口样式，不更新卡片状态、尺寸或坐标，不隐藏正文或悬浮区。

依据：[Chrome 关于缩放重绘与 will-change 的说明](https://developer.chrome.com/blog/re-rastering-composite)。隔离 Edge 的两轮对照中，Paint 累计耗时约减少 50%，RasterTask 累计耗时约减少 91%，详见[缩放性能验证](缩放性能验证.md)。已检查真实滚轮连续操作时保持合成提示、停下后释放，正文和编辑器 DOM、坐标、尺寸与草稿不变。该结果不能代替用户真实 Electron 桌面的帧率和清晰度验收。

0.6.2 对标题栏增加独立的排版尺度。初始化时读取实际视口比例；每次缩放结束后，仅在标题元素写入 `--st-header-scale`，不在中间帧修改。标题使用 CSS `zoom: z` 排版文字，再用 `transform: scale(1 / z)` 抵消祖先画布的缩放，维持同样的位置与宽度。浏览器按实际显示字号布局标题，而非只依赖视口缓存提示恢复清晰度。正文、输入框、节点矩形与数据不变，标题高度的像素取整差异由原有 ResizeObserver 同步到遮罩。问题标题采用 DSH 主文字色，提高其与类型标签的区分度。机制依据：[CSS Viewport 的 zoom 定义](https://drafts.csswg.org/css-viewport/#zoom-property)（编辑草案）。

## 验证与限制

32 项自动化测试覆盖布局、分支、存储、原生输入记录及缩放策略。隔离 DSH Web、Edge 和本地测试模型验证卡片与右侧独立草稿、切换及重载恢复、实际原生提交、引用提交与高亮、深浅主题、圆角菜单、440px 窗口、四向节点避让、尺寸扩大与缩小及重载恢复。0.6.2 另在独立的 Electron 44.7.0 / Chromium 152 离屏窗口、设备倍率 1.5 中验证标题从 28% 到 165% 的排版与几何、缩放中零次标题变量更新、结束后一次更新、放大后拖动及重载恢复。

悬浮区外沿通过显示/隐藏正文的截图像素对比验证没有底层文字漏出；正文末尾可滚到输入区上方。成功流程没有页面错误或警告。真实桌面文字清晰度、真实模型长时间输出、完整附件上传及语音/多插件组合仍需验收。本轮不更改桌面 GPU 设置，不自动重启用户 DSH。
