# 节点自适应布局实施计划

**目标：** 缩放画布时保留卡片内容；拖动、扩大和缩小卡片时，相邻节点自动让位或适度回收空隙，避免重叠。

**设计：** React Flow 继续负责鼠标拖动、缩放、尺寸控制和连线。插件只处理节点矩形的间距约束。以手势开始时的坐标为基准计算，操作中的卡片跟随鼠标，其余卡片由近及远避让。最小间距先设为画布坐标 48px；缩小时只牵引原本相邻（边缘间隔不超过 96px）且方向相符的卡片及相连邻居，不全局重排。一次手势内返回原位置时，被推开的节点回到该次手势的初始位置，避免持续累积位移。

**约束：** 不新增画布框架；不在平移或缩放时运行布局；不因缩放折叠正文或移除输入框。实时坐标仅更新 React Flow 的本地节点状态，松手时统一保存。保留实际测量、手动尺寸、曲线和圆角折线。自动布局仍由用户显式触发。

**验收重点：** 四个方向的直接避让、连锁避让、大步拖动跨过邻居、缩小回收、扩大后反向恢复、角点缩放、自定义尺寸、低于 60% 缩放时的正文/输入/选区持续存在，以及整个手势中不写入设备偏好。

## 执行步骤

- [x] 实现局部矩形约束求解，不对画布视角变化做计算。
- [x] 将求解接入 React Flow 的拖动和 NodeResizer 尺寸变化，保留测量及 DOM，统一在松手时保存坐标和尺寸。
- [x] 删除按缩放比例隐藏卡片正文、输入区的逻辑；适配自然内容高度变化及恢复默认尺寸。
- [x] 构建并运行自动化测试，在隔离 DSH 环境中实际拖动、缩放、调整尺寸并检查每帧间距、恢复、持久化和错误。
- [x] 更新设计与开发记录，提交并推送开发分支，保持 main 不变。

验证记录：初始占位实现的 10 项几何测试全部失败；实现后通过，并追加负坐标和空间分区场景。当前共 20 项自动化测试通过。浏览器逐步验证四向拖动各 15 个阶段、连续扩大/缩小、正文 DOM 保留、坐标与宽高重载恢复、键盘移动以及手势期间零偏好写入。回归覆盖原生模型/权限菜单、两种输入提交、分支隔离、引用高亮、连线 DOM、长文和窄窗口、点阵与主题。未启动或重启用户实际桌面应用，验证仅使用隔离配置与测试模型。

当前验证使用现有 Edge 和 Playwright，Browser 插件未提供。真实桌面上此前的闪隐/追帧问题不作为此布局功能已解决的结论。
