# Markdown 和代码卡片实施计划

资料卡保存在学习树的同一份会话日志中。资料卡可以从当前节点新建，也可以从选区创建并保留来源。资料卡的改动以保存时的版本记录，布局等显示偏好沿用画布现有逻辑。

1. 在 `treeLog.js` 和 Host RPC 中实现资料版本重放与保存。校验目标会话、父节点和预期版本。资料追问的画布父节点是资料卡，模型的父边界为最近的祖先问答。用单元测试检查交错分支和修改后的重放。
2. 在 `CanvasTools.tsx` 的底部工具栏中提供「添加卡片」，`StudyPage.tsx` 接入选区摘录。新建后聚焦正文编辑器，停笔或离开时保存。资料卡复用问答卡的默认尺寸、调整把手、圆角和悬浮输入框。代码始终显示行号和实时高亮，Markdown 由用户切换预览。
3. 在现有原生输入通道中加入资料全文和选区。右侧继续使用原生问答视图。引用可以回到资料原文或提问时的历史版本。
4. 用官方 DSH 隔离验收编辑保存、划词追问、普通追问、日志恢复和兄弟分支隔离。对原有问答卡和原生视图运行回归测试。
