# 原生单轮卡片实施计划

> 按 `superpowers:executing-plans` 执行，独立任务可按 `superpowers:subagent-driven-development` 分工；基于已确认设计，不重复请求批准。当前检出为专用开发分支 `feat/native-turn-cards`。

**目标：** 16:9 默认卡片，实时单轮原生回复与工具过程，在卡片内处理原生待交互请求，保留分支隔离及画布性能。

**架构：** 复用 Session/Conversation 的 Chat 组装结果和原生 keyed renderer，按本轮边界显示。运行会话与下一轮草稿分离，待交互面板单实例路由，流式正文使用每节点订阅。

**技术栈：** DSH 0.2.2-rc.3、宿主 React、SlotRegistry、React Flow、Node tests、隔离 DSH + Edge。

## 1. 尺寸与兼容流读取
- [x] `src/client/cardSize.ts` 统一默认 640×360、最小 480×270；更新 `layout.ts`、`useAdaptiveNodes.ts`、`StudyPage.tsx` 和 CSS。
- [x] `tree.ts` 修复 partial/final 转正、多 Step 与 attempt 重试，新增 `test/turn-stream.test.mjs`；先红后绿。
- [x] 运行节点不挂下一轮输入；紧凑的停止/状态代替灰色伪编辑器。

## 2. 原生单轮展示
- [x] 新增 `NativeTurn.tsx` / 数据切片 helper，声明插件自己的 keyed slot 并镜像原生节点渲染注册。
- [x] 按 `requestId` 找真实轮次，以本轮索引/节点 key 显示 Assistant、工具、错误及过程，不显示祖先或重复原始提问。
- [x] 设置原生样式边界、Markdown 委托、节点 Store/字典/扩展 Factory 上下文；保留选区与引用锚点。
- [x] 只有本轮状态驱动其呈现，不通过每 token 全局 `Study.emit()` 重新渲染整树；完成数据缓存供导出与回退。
- [x] 真实分段流测试：首段在结束前可见、多次增量、工具执行状态/详情、最终结果无重复、固定节点矩形与连线身份。

## 3. 原生待交互路由

- [x] 只路由到当前运行 Session 对应的选中卡片，使用宿主原动作；回到普通对话/卸载时恢复原位置。
- [x] 提问、计划确认、权限处理，以及正在生成的停止动作，不使用下一轮 fork。运行结束且无待交互才恢复追问编辑器。
