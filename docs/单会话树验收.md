# 单会话学习树验收

使用本分支和配套的 DeepSeek Harness `feat/single-session-tree` 构建。原版 0.2.2-rc.5 的输入组件会提示升级宿主。旧版 fork 学习树仍可阅读，首次使用新结构时新建学习主题。

在插件仓库运行 `npm ci`、`npm test` 和 `npm run build`。单元测试包含清空插件索引后从宿主日志重建、空闲压缩后的父边界，以及异步问询续轮与原卡片的对应关系。

## 浏览器与磁盘

以下命令适用于 Windows PowerShell 7。把两个仓库检出到同级目录，在插件仓库打开终端。使用宿主要求的 Node 和 pnpm 版本。先构建宿主与插件。

```powershell
$pluginRoot = (Resolve-Path .).Path
$hostRoot = (Resolve-Path ../deepseek-harness).Path
pnpm --dir $hostRoot install --frozen-lockfile
pnpm --dir $hostRoot run build:artifacts
npm ci
npm run build
```

创建单独的测试目录，为 Web profile 注册已构建的插件。模型替身监听本机 54382 端口，Web 界面使用 54841。所有会话、工作目录和模型请求记录都写在临时目录中。

```powershell
$qaRoot = Join-Path $env:TEMP ('study-tree-qa-' + [guid]::NewGuid())
$env:DSH_HOME = Join-Path $qaRoot 'home'
$env:DSH_QA_OUTPUT = Join-Path $qaRoot 'model'
$env:DSH_QA_LOG = Join-Path $qaRoot 'web.log'
$env:DSH_QA_SESSIONS = Join-Path $env:DSH_HOME 'sessions'
$env:STUDY_MOCK_API_KEY = 'local-test'
$profileDir = Join-Path $env:DSH_HOME 'profiles/study-tree-qa'
New-Item -ItemType Directory -Path "$profileDir/node_modules", "$qaRoot/documents" -Force | Out-Null
$env:DSH_QA_DOCUMENTS = node -e "process.stdout.write(require('node:fs').realpathSync.native(process.argv[1]))" "$qaRoot/documents"
New-Item -ItemType Junction -Path "$profileDir/node_modules/dsh-study-tree" -Target $pluginRoot | Out-Null
@{
  private = $true
  dependencies = @{ 'dsh-study-tree' = 'link:' + $pluginRoot.Replace('\', '/') }
  dsh = @{ profile = @{ bundles = @('@deepseek-ai/dsh-base', '@deepseek-ai/dsh-web-app', 'dsh-study-tree') } }
} | ConvertTo-Json -Depth 5 | Set-Content "$profileDir/package.json"
'[]' | Set-Content "$profileDir/cordis.yml"
# 在测试 profile 中预先关闭此版本的首次欢迎弹窗，供浏览器自动化使用。
@'
- id: ui-settings-general
  config:
    welcomeNoticeVersion: 2026-09-28.1
'@ | Set-Content "$profileDir/cordis.patch.yml"

$mockJob = Start-Job -ArgumentList $pluginRoot -ScriptBlock {
  param($pluginRoot)
  node "$pluginRoot/scripts/qa/mock-model.cjs"
}
$webJob = Start-Job -ArgumentList $hostRoot,$pluginRoot -ScriptBlock {
  param($hostRoot, $pluginRoot)
  node --expose-internals "$hostRoot/apps/cli/lib/bin.js" --profile study-tree-qa --patch "$pluginRoot/scripts/qa/model.patch.yml" --no-open --port 54841 2>&1 |
    Out-File -Encoding utf8 $env:DSH_QA_LOG
}
```

等 `Get-Content $env:DSH_QA_LOG` 显示本机访问地址，在同一终端运行下列验收。浏览器默认使用本机 Edge，`DSH_QA_BROWSER` 可以指向其他 Chromium 可执行文件。结束后运行 `Stop-Job $webJob,$mockJob` 关闭这两个测试进程。

```powershell
node scripts/qa/session-paths.cjs
node scripts/qa/selection-navigation.cjs
node scripts/qa/native-questions.cjs
node scripts/qa/native-approvals.cjs
node scripts/qa/native-reload.cjs
```

路径用例先发送 A，从卡片继续 B，返回 A 从右栏发送 C，再从 B 发送 D。首轮至末轮的 Session ID 相同，磁盘始终只增加一个 session 日志。模型请求记录中，C 继承 A，D 继承 A、B。右栏选中 D 时显示 A、B、D。其余用例分别覆盖选区草稿、会话中的问题确认、审批，以及流式回答期间刷新恢复。
