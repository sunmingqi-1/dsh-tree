# 官方 DSH 上的单会话学习树验收

适用版本为 DSH Desktop 0.2.2-rc.5 和插件 0.9.0-rc.1。在 Windows 插件仓库中使用 Node.js 24 和本机安装的 Edge。官方安装目录和安装包路径可按实际情况调整。

```powershell
npm ci
npm test
npm pack
node scripts/qa/stock-package.cjs ./dsh-study-tree-0.9.0-rc.1.tgz 'D:\Application\DSH'
```

脚本在临时目录中新建 desktop 和 web 两份 profile，通过官方 CLI 安装同一个压缩包。它从已安装的官方程序启动本机测试服务，使用 Edge 操作原生输入框，并由本机模型替身记录每次真正收到的上下文。临时目录包含启动日志、会话目录与请求记录，脚本开头会打印路径。

| 操作 | 验收结果 |
| --- | --- |
| 新建 A，从 A 输入 B，再返回 A 输入 C，最后从 B 输入 D | 四次提问只有一个会话 ID 和一份权威会话日志 |
| 检查模型请求中的测试标记 | 依次为 A、AB、AC、ABD |
| 选中 D | 阅读区沿 A、B、D 显示原始消息 |
| 新建普通对话并发送消息 | 使用原来的线性流程 |
| 完全关闭宿主，再用新浏览器打开 | 学习树和普通会话均能从磁盘恢复 |

集成用例还会在 B 完成后调用官方 `/compact`。它检查磁盘上的摘要和消息替换记录，再分别从 A、B 追问，核对模型收到的内容，并在重启后重复检查。

分支压缩回归使用同一真实 Session。从 A 分出 B、C，在两条路径上各压缩同一祖先，再从 B 提问。除模型可见消息外，还核对请求头、工具声明和恢复后的祖先边界。宿主日志仍完整保存 A、B、C、D 的原始事件。重新打开后可以继续阅读原文。

单一日志指一份权威会话事件流。DSH 仍可维护索引、附件、写锁和投影缓存。运行环境组件的来源和适配差异见 `runtime/NOTICE` 与 `runtime/patches/`。

## 插件接管的职责

| 环节 | 插件做的事 |
| --- | --- |
| 原生输入 → Agent | 用发送请求 ID 绑定已完成的父节点。在同一会话中排队时，每个提问带着自己的父节点。 |
| 会话与 JSONL | 物理序号仍按发生顺序递增。树的标记、父边界和分支压缩记录随日志落盘。重新打开时根据父边界恢复路径。 |
| 模型请求与压缩 | Agent、上下文投影和 token 计量读取当前路径。DSH 原生压缩器在这条路径上执行，成功的摘要仅对其后代生效。 |
| 延迟任务 | 工具提问、子 Agent 和后台任务的延迟结果按发起回合归属，返回其他分支时可以继续各自的工作。 |
| 查询与界面 | 导出会话可读取完整事件流。画布按回合生成卡片，右侧阅读区按父节点显示历史。 |

`cordis.patch.yml` 列出装配的官方服务和对应的插件入口。适配继承原 profile 的配置，包括会话目录、存储压缩选项和预设工具参数。适配使用了 rc.5 的 Session 内部接口，宿主升级时需要按新版本重新核对补丁并运行上述用例。
