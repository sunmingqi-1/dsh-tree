# 原生单轮卡片（0.7.0）

## 行为

- 新卡片默认 640×360（16:9），最小调整尺寸 480×270；旧手动尺寸不重写，手动调整不锁定比例。
- 卡片实时显示本轮原生 Assistant、推理、工具及结果，不重复显示祖先回复和顶部的问题。
- 流式生成不改变外部矩形。正文底部跟随新内容，向上滚动后暂停跟随。
- 生成时用紧凑状态与停止按钮替代下一轮编辑器；等待用户输入或审批时展示当前运行会话的原生面板；结束后恢复原生追问编辑器。
- 点击原生「已完成，用时…」折叠或展开过程。默认展开，当前设备记住手动选择；最终正文、回答操作与问答回显保留。生成中和没有最终答案时保持过程可见。
- 右侧仍是 DSH 原生会话，保留输入、拖宽及收起功能。待交互面板在原位置与卡片之间移动同一个 DOM 容器，保持表单实例和草稿。

## 接入与隔离

适配版本为 DSH 0.2.2-rc.3。同级源码与安装版公开运行时存在 `uiSession.pendingInteractions` 和 `uiSession.sessionStatus` 两种状态入口，适配器同时支持。安装版实际测试通过，不能仅根据版本号推断接口完全相同。

`NativeTurn.tsx` 复用公开 SlotRegistry 中原生 Chat 的注入、Store、字典及 keyed 节点注册，按请求所属真实 Turn 切片。Markdown 使用原生委托，保留代码块、文件操作和图片能力。没有复制 `ChatView` 或 `ChatFlow` 私有源码，也没有给每张卡片挂载整页聊天。

公开接口没有独立导出的 Step 分组容器，当前按原生逐节点、逐工具展示；整轮折叠根据公开 `TurnProcessSpec` 计算，工具详情沿用原生控件。其布局不是完整 `ChatFlow` 分组逻辑的副本。

每行订阅自己的原生节点，正文 token 不调用全局 `Study.emit()`。请求到轮次索引缓存、结构签名及镜像注册的增量更新避免重新装配整树。原生内容准备好后卸载备用 Markdown。Session 引用按卡片释放，同会话绑定按计数清理；加载失败释放引用并提供重试，连接重置后重新绑定。

`NativeInteraction.tsx` 在原生 composer chain 里路由面板，保留原生 selector、Store 和动作。归属通过工具 callId 或首次可确定的 openTurn 解析，并按 pending key 固定；无法确定时留在原生位置。停止操作现场检查当前运行轮。下一轮草稿 fork 不承接当前轮提问、审批或停止。系统来源的 `user-question-reply` 不创建学习子节点。

镜像跟随父 Slot 生命周期，忽略销毁后已经排队的订阅回调。曾在答题回显中复现该回调重复声明 `plan-review.actions`，现已修复并加测试。

划词引用只取可见 Assistant 正文，忽略工具、状态和折叠过程；公式整体及跨越非正文区域的选区暂不作为引用源。正文选择、原生引用输入和失焦高亮已验证。

使用独立 `DSH_HOME`、本地 Anthropic 协议 mock 和实际安装版 DSH，在 Edge 中验证：

| 场景 | 结果 |
| --- | --- |
| 多次分段流式输出 | 结束前可读、持续追加、最终正文不重复 |

普通阻塞提问已做端到端测试；计划审查沿用原生路由，跨 Turn 的定时/迟到答复未做端到端验收，不宣称已经覆盖。

## 缩放对照

从 `main` 的 0.6.4 构建基线，只在隔离浏览器的资源响应里替换插件产物，没有切换用户安装目录。相同两张长文卡片，统一 640×360，1600×1000 视窗、DPR 2，约 3 秒相同滚轮序列：

| 指标 | 0.6.4 | 原生单轮卡片 |
| --- | ---: | ---: |
| 无头浏览器 rAF 间隔 p95 | 4.3ms | 4.3ms |
| 间隔超过 33.5ms | 0 次 | 0 次 |
| Layout 累计 | 72.2ms | 66.7ms |
| Paint 累计 | 112.6ms | 85.1ms |

该样本未观察到新增长帧。这是单次浏览器对照，不能换算成桌面屏幕帧率，也不能保证大规模树或所有设备表现相同。保留既有缩放缓存及停止后清晰重绘策略。

## 复测

`scripts/qa` 仅用于隔离 DSH，不连接真实模型。安装当前构建到单独测试配置，使用附带的 `model.patch.yml` 指向本地 mock，并设置 `STUDY_MOCK_API_KEY=local-test`。启动 DSH 时将本地测试地址写到日志，通过 `DSH_QA_LOG` 指向它；不要公开日志中的登录地址。

```powershell
npm ci
npm run build
# 第一个终端
node scripts/qa/mock-model.cjs
# 第二个终端：启动隔离 DSH，并设置 DSH_QA_LOG 后依次执行
node scripts/qa/native-turns.cjs
node scripts/qa/native-questions.cjs
node scripts/qa/native-approvals.cjs
$env:DSH_QA_REJECT = '1'
node scripts/qa/native-approvals.cjs
Remove-Item Env:DSH_QA_REJECT
node scripts/qa/native-reload.cjs
```

`DSH_QA_BROWSER` 可指定浏览器，`DSH_QA_OUTPUT` 可指定 mock 日志目录，默认写入系统临时目录。权限测试仅执行 `Write-Output native-card-approval`，拒绝用例不会执行该命令。
