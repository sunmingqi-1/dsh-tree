# 学习树 · 产品与交互设计

**项目名为 `dsh-study-tree`，在 DSH 中显示为「学习树」。** 名字对应用户保存和重新打开的东西：围绕一个主题，通过追问长成的一棵树。每个节点恰好对应用户的一问和 Agent 的一轮回答。

当前开发版本为 0.6.4。以 DSH 原生工作区、原生起始页、完整原生会话及原始输入组件为基础，新增画布及节点导航。实现与实际验证范围见[开发计划](开发计划.md)。悬浮卡片的布局及输入接入细则见[悬浮卡片与原生输入设计](悬浮卡片与原生输入设计.md)。

## 用一次学习过程验收设计

根节点问「学习 DSH 从哪里开始？」。读到回答里的「工具调用」，选中这四个字，追问「举一个实际例子」。新回答又提到「JSON Schema」，从这里再问「为什么要描述参数类型？」。读完后点「返回原文」，应先回到「JSON Schema」出现的那句话，再返回上层的「工具调用」。这时仍能在根节点另开「上下文管理」，右栏只显示根节点与这条新问答。第二天打开同一棵树，还能定位此前读过的原句。

## 三栏与输入

| 区域 | 内容与操作 |
| --- | --- |
| DSH 原生工作区区域 | 在已有工作区内，学习主题作为可展开项，其后代按问答节点的父子关系缩进、折叠。一项对应一个画布节点，标题使用该轮的问题。点击主题或追问，在主区域打开对应画布并选中节点；恢复该树的画布视角和阅读位置。 |
| 中央无限画布 | 一个节点一轮问答，正文渲染 Markdown。沿上到下的方向按父子关系连线，同级分支左右并列。选中节点时突出从根到它的路径。拖动空白平移，通过卡头移动卡片，正文可正常划词、复制、滚动。远处看问题标题，拉近后读问答。 |
| 右侧原生对话区 | 沿用 DSH 自己挂载的完整会话界面，包括会话标题、模式、输入框和当前安装提供的对话、统计等页签，呈现从根节点到当前选中节点本轮结束的内容，保留宿主已有的消息、代码和工具调用详情展示。采用原生消息布局。对话区与画布同时显示，左边界可拖动调宽，也可收起，重开时恢复宽度与同一路径的阅读位置。 |

新建主题使用 DSH 原生起始页。模式选择右侧放置「分支图标＋学习画布」入口，与工作区、模式控件同高、同字号及圆角，默认无描边，悬停显示原生主题底色。入口为启动动作，点击后沿用原生输入框选择模型、模式与工作区并发送首个问题，该轮问答自动记录为根节点，画布随即显示在原生会话左侧。激活后入口隐藏，保留输入 DOM 和草稿；窄窗口中可压缩标签或换行。

后续点击节点，在卡片底部悬浮显示 DSH 原始输入组件。保留默认加号、权限、模型及发送入口；隐藏卡片内的统计行，压缩编辑区空白。附件、命令、语音等能力由当前宿主原生组件提供。输入与发送键盘行为沿用宿主，草稿按对应节点的独立分支会话保存。

首轮之后，右侧保留宿主原有会话及输入区。卡片、划词胶囊和右侧输入框都可提交追问。右侧仍走 DSH 的原生提交过程，插件观察新的用户消息并记录为当前节点的子节点。若源会话已有该节点之后的历史，则先准备截止本轮结束位置的分支，再开放右侧输入，避免继承后续问答。准备的分支按节点缓存，不在左侧增加独立目录项。左侧列表项、画布节点和右侧路径共用当前节点 ID，任一处定位或切换后同步另外两处。原生对话组件内的正文选择、复制、滚动和详情展开继续可用。

在卡片或阅读区的 Agent 正文中划词，右键打开并聚焦选区旁的简化原生输入框。默认插入原生引用与「请解释引用的内容。」；可以编辑问题或移除引用，Esc 取消。引用属于实际被选中的回答，即使读者正从更深的节点浏览祖先消息。成功后选中新子节点，来源卡的原有草稿保留。

选区使用独立的浏览器 Highlight 保存可见状态，焦点进入胶囊或卡片输入框时不会消失；Esc、点击画布空白处、切换节点或发送成功后清理。该高亮与「返回来源」的短时定位高亮相互独立。

### 卡片阅读与尺寸

默认卡片 560 × 360px，采用宽而矮的比例。悬浮标题栏显示节点类型和问题，引用节点增加来源摘录，背景使用 DSH 原生输入框颜色；去除「我的问题」「DSH 回答」「一轮问答」等重复标签及「展开阅读」，不再提供恢复默认尺寸按钮。卡片始终挂载完整 Markdown，正文在全卡范围内滚动，悬浮栏与输入框不缩短滚动视口。正文顶部、底部使用渐变遮罩，遮住悬浮区域边缘的底层文字，同时保留悬浮观感和末尾留白。选中卡片显示 React Flow 原生 NodeResizer，四边和四角均可调整大小，最小 420 × 300px。尺寸在松手时保存，自动布局读取实际宽高，已有手动尺寸保留。

## 工作区中的层级列表

侧栏沿用 DSH 工作区区域，移除独立的「学习树」导航项和账户菜单上方的「学习目录」。工作区内可同时出现普通会话与学习主题。学习主题自身就是根问答，展开后显示它的子节点；继续展开子节点可浏览更深的追问。

```text
工作区
  ▾ 学习 DSH
      ▾ 请介绍整体架构
          ▾ 工具调用如何实现？
              JSON Schema 是什么？
          上下文如何管理？
      如何开发插件？
  其他普通会话
```

层级与画布的父子边一致。展开、折叠只改变目录的可见性；切换主题时保存各自的展开状态。选择深层节点时显示其祖先，侧栏选中项与画布路径同步。主题内按创建顺序排列同级节点，保持分支位置稳定；普通会话沿用宿主原有排序。

插件依据持久化的节点与会话映射聚合学习会话，使每个学习节点在所在工作区内只出现一次。现有学习树与会话继续使用原 ID。目录迁移时从根会话的实际工作区恢复归属，子节点随主题归组；无工作区的主题显示在「未分组」中。列表按每个节点自己的问题命名，避免分叉继承的会话标题造成混淆。普通会话保留宿主原有的打开方式。

DSH 当前的工作区树按已登记目录的路径组织，会话行本身仍为平铺。实现本设计需要扩展工作区会话列表的渲染和导航，再复用现有工作区数据及行操作。具体扩展方式须在本地宿主中验证，接入依据见 [DSH 插件接入](DSH插件接入.md)。

## 回到原句与长文阅读

- 子节点保留引用摘录和「返回原文」。定位来源时恢复来源卡的展开状态与阅读位置，必要时展开文本，再短暂高亮原句。同一短语出现两次时按消息标识、文本块、偏移及前后文区分；无法唯一定位时展示原摘录并定位到来源消息。
- 卡片始终显示完整长回答并在内部滚动，缩放不隐藏正文；右侧使用原生组件连续阅读完整内容。代码块和宽表格在自身区域横向滚动，卡片中的 Markdown 排版与宿主正文保持视觉一致。划词和返回定位使用统一的可见文本规范。正文保留可复制代码和可选择文本，卡片渲染禁用原始 HTML。
- 画布、卡片、文字、边框和输入区读取 DSH 默认主题变量，随宿主明暗主题变化。保留约 18px 卡片圆角和细连线。选中态同时有轮廓和路径线。输入区、流式增长、折叠和阅读栏拖动均保持当前阅读锚点；Dagre 用于初次布局和显式整理，后续插入优先使用邻近空位。小窗口先收起目录和阅读区，保留画布及重新打开入口。

## 纵向布局与连线

父节点从卡片底部连接子节点顶部，树沿上到下的方向延伸。画布底部工具栏提供两种连线方式，默认使用曲线。圆角折线沿水平与垂直方向连接，转角采用 12px 圆弧。连线方式作为当前设备的偏好保存，切换后即时作用于当前画布。

「自动布局」按卡片实际宽高安排节点，同一层的问题标题顶端对齐，父子之间保留间距，并将整棵树适配到画布视野。操作只重新排列当前学习树，当前选中节点、问答及原生对话路径继续保留。

普通连线采用 DSH 次级文字色与边框色的混合，提高在背景上的对比度；当前路径使用主题强调色与主文字色的混合，保持蓝色辨识。普通线宽为 2px，当前路径为 2.5px，使用 SVG non-scaling-stroke 保持屏幕线宽，避免缩小时线条过细；曲线与圆角折线共用此规则。

画布右下角加入 176 × 120px 小地图，直接复用 [React Flow MiniMap](https://reactflow.dev/api-reference/components/minimap)。显示节点矩形、选中节点蓝色填充及当前视野框，使用 DSH 主题背景、圆角与细边框。点击位置用 120ms 过渡将该世界坐标移到画布中央，拖动小地图平移视野；这些操作不改变节点选择、节点位置或问答内容。小地图不重复渲染 Markdown，不增加独立的相机状态。画布宽度不超过 900px 时上移，为底部工具栏留出空间；不超过 380px 时进一步避让可能换行的按钮。小地图沿用原生的只读概览，不额外提供滚轮缩放入口。

小地图的程序平移只在实际缩放比例发生变化时触发最终文字刷新，避免将每次相机平移都误判为缩放并重排标题。原画布滚轮规则保持原样。

初次迁移已有横向画布时，重新计算纵向坐标并记录该树的布局版本。之后新增节点优先放在父节点下方，遇到已有卡片时在同一行向右避让，保留原有卡片的位置。长文、输入区和手动尺寸变化采用下述自适应避让；显式「自动布局」可重新收紧整棵树。

### 0.5.0 自适应避让

画布缩放仅改变显示比例，卡片正文、输入区、手动尺寸及内容展开状态均保留。不再设置按缩放比例触发的自动折叠或隐式放大。

拖动和改变卡片宽高时，正在操作的卡片保持鼠标所指定的位置/尺寸；周围卡片由近及远，向四个方向让位，最小间距为画布坐标 48px。快速移动跨过整个邻居时，按移动轨迹检查接触，避免直接穿过邻居后交换顺序。扩大卡片会推开邻居和连锁受影响的节点；缩小时，仅牵引原先边缘距离不超过 96px、且在对应方向投影相邻的节点及其接触链，保留其原有间距。远处不相交的节点保持位置。

每次手势以开始时的矩形为基准，而不是在上一帧位移上叠加。这样在一次拖动或调整尺寸中反向操作，临时推开的节点可回到初始位置，不持续漂移。其他实际尺寸变化也采用同样的邻居避让规则。

React Flow 保留拖动、NodeResizer、测量和连线的控制。插件使用空间分区筛选潜在邻居，在原生节点变化事件中更新本地坐标；平移和缩放视角不运行避让，不更新尺寸或正文 DOM。松手时一次保存当前所有节点坐标和本次手动尺寸，显式「自动布局」继续使用 Dagre。键盘移动节点也执行间距约束并保存。

## 节点、会话与学习笔记

| 记录 | 需要的数据 |
| --- | --- |
| 学习树 | 稳定 ID、标题、工作区、根节点 ID、版本 |
| 问答节点 | 稳定 ID、树 ID、父节点 ID、继续或引用关系、DSH 会话 ID、本轮起止事件序号、状态 |
| 引用锚点 | 来源节点、源消息标识、文本块与可见文本偏移、选区原文、前后文；以同一文本规范提取和匹配 |
| 阅读状态 | 每棵树的选择、坐标、缩放、展开状态；每节点草稿、返回原文位置，阅读区宽度及可见性 |

DSH 会话日志保存问答正文；插件 Host 保存树结构、引用和请求关联，客户端保存设备上的阅读偏好。节点身份独立于宿主轮号，兄弟分支完全可能拥有相同轮号。右栏的可见轮次与 Markdown 导出共用同一条路径计算。整树导出按分支嵌套输出，每节点包含自己的问答与来源摘录。

首版以**精确边界优先**。根问答通过原生新会话完成并记录来源请求。每个后续节点，无论从卡片继续还是从选区追问，均从父轮已完成的结束序号 fork，随后提交本次问题与可选引用。这样普通追问和历史节点追问使用同一规则，递归分支只继承祖先历史，DSH 仍负责系统提示、工具及上下文压缩。每次追问会增加一个宿主会话并复制历史，成本验证见[开发计划](开发计划.md)。生成期间可以先写追问草稿，待父轮具有可用边界再发送。

原生阅读区的输入数据按插件记录的祖先链和结束序号确定。已完成节点展示截止该轮结束的内容，生成中的当前节点随本轮事件更新；宿主会话后来追加的内容保持在对应节点边界之外。继承历史只展示一次。工具调用、返回结果及消息详情需能关联到各自所属的问答节点，从祖先正文划词时仍能正确确定引用来源。

历史问题的改写或重新生成作为同一来源下的新版本保留，原有回答和后代仍可访问。改写根问题时新建同主题的树并链接来源，以保持每棵树只有一个根。重新答复、导出和大树性能优化安排在基本学习流程通过后。

## 中断与恢复

提交、生成中、完成、停止和失败分别呈现。先落盘操作 ID、来源和草稿，再记录 fork 返回的目标会话 ID，最后用已持久化的用户消息和结束记录对账。已知目标会话时继续使用该会话；提交结果未知时先核对宿主历史。若创建结果丢失且无从可靠识别，保留草稿、告知状态未知，由用户决定是否重新发起。来源会话被移除时保留树的位置和已存摘录，清楚标记正文不可用。

插件入口与宿主接口见 [DSH 插件接入依据](DSH插件接入.md)。

右侧原生对话默认宽度为 480px，可继续拖动调整。画布菜单中的「打开完整对话」恢复原生全宽会话。
