# 学习树 · 产品与交互设计

**项目名为 `dsh-study-tree`，在 DSH 中显示为「学习树」。** 名字对应用户保存和重新打开的东西：围绕一个主题，通过追问长成的一棵树。每个节点恰好对应用户的一问和 Agent 的一轮回答。

## 用一次学习过程验收设计

根节点问「学习 DSH 从哪里开始？」。读到回答里的「工具调用」，选中这四个字，追问「举一个实际例子」。新回答又提到「JSON Schema」，从这里再问「为什么要描述参数类型？」。读完后点「返回原文」，应先回到「JSON Schema」出现的那句话，再返回上层的「工具调用」。这时仍能在根节点另开「上下文管理」，右栏只显示根节点与这条新问答。第二天打开同一棵树，还能定位此前读过的原句。

## 三栏与输入

| 区域 | 内容与操作 |
| --- | --- |
| DSH 原生左侧栏 | 学习目录位于账户菜单上方，一项代表一个主题。创建、命名、切换学习树；返回已打开的树时恢复选择和画布视角。 |
| 中央无限画布 | 一个节点一轮问答，正文渲染 Markdown。按父子关系连线，选中节点时突出从根到它的路径。拖动空白平移，通过卡头移动卡片，正文可正常划词、复制、滚动。远处看问题标题，拉近后读问答。 |
| 右侧路径阅读 | 沿父指针从当前节点回到根，反转后逐轮展示。用户气泡靠右，Agent 气泡靠左，两条消息有独立间距；点击「定位节点」回到画布对应卡片。阅读区左边界可拖动调宽，也可收起，重开时恢复宽度与同一路径的阅读位置。 |

点击节点，只在该卡下方展开一个输入框。采用已确认的 Codex 式圆角输入区，正文在上，操作和发送按钮在下；Enter 发送，Shift+Enter 换行，中文输入法确认候选词时不发送。按节点保存草稿。

在卡片或阅读区的 Agent 正文中划词，右键打开并聚焦选区旁的单行胶囊输入框。输入可选问题后发送；留空发送采用「请解释『选中文字』」。Esc 取消。引用属于实际被选中的回答，即使读者正从更深的节点浏览祖先消息。成功后选中新子节点，来源卡的原有草稿保留。

## 回到原句与长文阅读

- 子节点保留引用摘录和「返回原文」。定位来源时恢复来源卡的展开状态与阅读位置，必要时展开文本，再短暂高亮原句。同一短语出现两次时按消息标识、文本块、偏移及前后文区分；无法唯一定位时展示原摘录并定位到来源消息。
- 卡片默认折叠长回答；右侧可连续读完整 Markdown。代码块和宽表格在自身区域横向滚动，引用、列表、代码和公式在卡片与阅读区使用同一渲染规则。正文渲染禁用原始 HTML，保留可复制代码和可选择文本。
- 使用中性灰阶、宿主明暗主题、约 18px 卡片圆角和细连线。选中态同时有轮廓和路径线。输入区、流式增长、折叠和阅读栏拖动均保持当前阅读锚点；Dagre 用于初次布局和显式整理，后续插入优先使用邻近空位。小窗口先收起目录和阅读区，保留画布及重新打开入口。

## 节点、会话与学习笔记

| 记录 | 需要的数据 |
| --- | --- |
| 学习树 | 稳定 ID、标题、工作区、根节点 ID、版本 |
| 问答节点 | 稳定 ID、树 ID、父节点 ID、继续或引用关系、DSH 会话 ID、本轮起止事件序号、状态 |
| 引用锚点 | 来源节点、源消息标识、文本块与可见文本偏移、选区原文、前后文；以同一文本规范提取和匹配 |
| 阅读状态 | 每棵树的选择、坐标、缩放、展开状态；每节点草稿、返回原文位置，阅读区宽度及可见性 |

DSH 会话日志保存问答正文；插件 Host 保存树结构、引用和请求关联，客户端保存设备上的阅读偏好。节点身份独立于宿主轮号，兄弟分支完全可能拥有相同轮号。右栏与 Markdown 导出共用同一条路径计算。整树导出按分支嵌套输出，每节点包含自己的问答与来源摘录。

首版建议以**精确边界优先**。根问答在新会话中进行；每个后续节点，无论从卡片继续还是从选区追问，均从父轮已完成的结束序号 fork，随后提交本次问题与可选引用。这样普通追问和历史节点追问使用同一规则，递归分支只继承祖先历史，DSH 仍负责系统提示、工具及上下文压缩。每次追问会增加一个宿主会话并复制历史，成本验证见[开发计划](开发计划.md)。生成期间可以先写追问草稿，待父轮具有可用边界再发送。

历史问题的改写或重新生成作为同一来源下的新版本保留，原有回答和后代仍可访问。改写根问题时新建同主题的树并链接来源，以保持每棵树只有一个根。重新答复、导出和大树性能优化安排在基本学习流程通过后。

## 中断与恢复

提交、生成中、完成、停止和失败分别呈现。先落盘操作 ID、来源和草稿，再记录 fork 返回的目标会话 ID，最后用已持久化的用户消息和结束记录对账。已知目标会话时继续使用该会话；提交结果未知时先核对宿主历史。若创建结果丢失且无从可靠识别，保留草稿、告知状态未知，由用户决定是否重新发起。来源会话被移除时保留树的位置和已存摘录，清楚标记正文不可用。

插件入口与宿主接口见 [DSH 插件接入依据](DSH插件接入.md)。
